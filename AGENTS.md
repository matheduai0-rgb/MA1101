# MA1101 Matematika I - Workspace Guidelines

## Overview
This repository serves as the academic workspace for **MA1101 (Matematika I / Calculus I)** at the Faculty of Mathematics and Natural Sciences (FMIPA), Institut Teknologi Bandung (ITB).

## Directory Structure
- `2025/`: Archives from the 2025/2026 academic year (e.g., UAS grade tables).
- `2026/`: Current academic year (2026/2027 Semester 1):
  - `K10/`: Class section 10 materials and records.
  - `K35/`: Class section 35 materials and records.
  - `K40/`: Class section 40 materials and records.
  - Master syllabus (`Silabus MA1101 Matematika I 2026-2027.pdf` and `.xlsx`).
  - Orientation files (`00 MA1101 Perkenalan dan Pengaturan.pdf`).
  - Tutorial and practice problem sets (`Tutorial_Bab0_...`, `Soal-Soal_Latihan_...`).

## Guidelines for AI Assistance
1. **Student Data Privacy**:
   - Roster spreadsheets (`Daftar Peserta Kelas...xlsx`) and grade files contain sensitive student data (NIM, names, attendance, scores).
   - Never modify or overwrite student rosters without explicit confirmation.
   - When generating scripts or templates, avoid hardcoding personal student identifying details into public scripts.
2. **Mathematical Standards**:
   - Course topics follow standard single-variable calculus (Limits, Derivatives, Integrals, Transcendental Functions, Applications).
   - Use standard LaTeX notation (`$...$` and `$$...$$` or `align*`) for mathematical formulas.
   - Reference standard textbooks used in the course (James Stewart, Adams & Essex Calculus).
3. **File Management**:
   - Maintain organized folders by academic year and class code (`K<number>`).
   - Keep backup files (`.bak`) ignored by Git.
   - If generating new question sets, provide corresponding answer keys and steps when asked.

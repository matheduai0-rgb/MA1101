# Bahasa Indonesia yang Mudah Dipahami (Diction Guide)

Slides are read in a lecture hall by first-year students who are also learning the calculus terms
themselves. Every unfamiliar word on a slide competes with the mathematics for attention. So the
goal is simple: **the only hard words on a slide should be the calculus terms the lecture is
teaching.** Everything around them (titles, labels, questions, hints, notes) uses everyday
Indonesian.

A lecturer who reviewed an earlier deck said the wording felt unfamiliar even though the structure
worked. The cause was coined labels ("Pemantik", "Formalisasi", "Uji Batas", "Tiket Keluar") and
long, formal sentences. Fix these first.

## Rules

1. **Say it the way a lecturer says it aloud.** Read each question out loud. If you would not say
   it to a student standing in front of you, rewrite it.
2. **Short sentences.** One idea per sentence, about 15 words at most. Questions should be one
   sentence.
3. **Active verbs, not noun-heavy phrases.** "Hitung kemiringannya" beats "Lakukan perhitungan
   terhadap kemiringan".
4. **Address students as "kalian"; the class together as "kita".** Avoid "Anda", "mahasiswa
   diharapkan", and passive "Tentukanlah" in questions. Problem statements may keep "Tentukan ..."
   as in the course texts.
5. **No coined stage names.** Titles say what students do, not the teaching method. Do not invent
   an abstract noun when a verb phrase works.
6. **Keep calculus terms exactly as the course uses them** (turunan, limit, aturan rantai, garis
   singgung, integral tentu, ...). Take them from `2026/` syllabus and tutorial files and earlier
   decks, not from memory. Do not "simplify" a technical term into a loose paraphrase; instead,
   explain it once in plain words the first time it appears.
7. **Define a new term right where it first appears**, in one short clause, then use it
   consistently. Do not switch between synonyms ("laju", "kecepatan", "kemiringan") for the same
   idea within one deck.
8. **Avoid English where Indonesian is common.** Prefer "tebak" to "prediksi" only if students
   say it; keep "prediksi" if it is already course vocabulary. When unsure, prefer the plainer word
   and keep the English in brackets once, e.g. "irisan (*slice*)".
9. **Presenter notes use the same plain style.** They are a script to be read quickly during class.

## Plain replacements for the deck's structural labels

Use the right-hand wording in titles and block labels. The left column is what to avoid.

| Avoid | Use instead |
|-------|-------------|
| Pemantik | Mulai dari Soal / Coba Dulu |
| Pertanyaan Besar Hari Ini | Pertanyaan Kita Hari Ini |
| Eksplorasi: ... / Eksplorasi Interaktif | Coba Geser: ... / Amati: ... |
| Prediksi → Amati → Jelaskan | Tebak → Amati → Jelaskan |
| Penemuan Terbimbing | Temukan Bersama |
| Formalisasi: Nama untuk yang Baru Kalian Temukan | Sekarang Kita Beri Nama |
| Definisi / Teorema (heading words) | keep as is; these are course terms |
| Kamus A ↔ Definisi | Cocokkan dengan Yang Tadi |
| Uji Batas | Apakah Ini Benar? |
| Benarkah Cara Dani? | keep; it is plain |
| Kesimpulan Kelas | Kesimpulan Kita |
| Refleksi / Dengan Kata-Kata Sendiri | Rangkum dengan Kata-Katamu |
| Tiket Keluar | Tulis Sebelum Pulang |
| Latihan Mandiri | Coba Sendiri |
| Contoh Terpandu / Contoh Setengah Jadi | Contoh Dikerjakan Bersama / Contoh: Lengkapi yang Kosong |
| Pahami / Rencanakan / Laksanakan / Periksa Kembali | Pahami Soal / Buat Rencana / Kerjakan / Periksa Lagi |
| Substitusi langsung | Langsung masukkan nilainya |
| Menyederhanakan bentuk | Sederhanakan |
| mode chips: Pikir 30 dtk, Diskusi berpasangan | keep; short and clear |

## Rewriting patterns for questions

| Stiff | Plain |
|-------|-------|
| Apa yang dapat disimpulkan mengenai perilaku kemiringan tali busur ketika titik Q mendekati titik P? | Kalau Q digeser mendekati P, apa yang terjadi pada kemiringan tali busur? |
| Jelaskan alasan mengapa substitusi langsung tidak dapat dilakukan. | Kenapa kita tidak boleh langsung memasukkan h = 0? |
| Identifikasi fungsi luar dan fungsi dalam. | Mana fungsi yang di luar, mana yang di dalam? |
| Manakah di antara pilihan berikut yang paling tepat? | Menurut kalian, A, B, atau C? |
| Verifikasi kebenaran jawaban Anda. | Bagaimana caranya kita yakin jawaban ini masuk akal? |

## Check before you finish

Skim every slide title, block title, and question. For each word, ask: would a student who has
only read the textbook chapter know this word? If not, replace it or explain it in one clause. Then
check the notes for the same.
